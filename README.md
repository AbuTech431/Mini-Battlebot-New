# Mini Battlebot Project

An autonomous and remote-controlled mini battlebot built with Arduino Nano. It features a spinning iron weapon to fight other robots and utilizes Bluetooth/NRF24L01 for wireless control.

## Project Description
This robot is designed for micro-robotics competitions. The main chassis holds four high-RPM DC motors driven by an L298N motor driver. It has built-in digital sensors for opponent tracking and smart logic for combat maneuverability.
